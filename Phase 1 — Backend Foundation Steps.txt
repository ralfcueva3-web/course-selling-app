# AI Learning Checklist for Course Selling App

## 1. Anthropic API Basics
- Read: https://docs.anthropic.com/en/api/messages
- What to understand:
  - How to make a POST request to /v1/messages
  - The request body shape (model, max_tokens, system, messages)
  - The response shape (content[0].text)
- Time: 30 minutes

## 2. Messages Array Format
- Read: https://docs.anthropic.com/en/api/messages
- What to understand:
  - { role: "user", content: "..." }
  - { role: "assistant", content: "..." }
  - How to pass chat history as an array of these objects
- Time: 20 minutes

## 3. System Prompts
- Read: https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/system-prompts
- What to understand:
  - System prompt is instructions before the conversation
  - How to inject dynamic data (course title, content) into a system prompt
  - Difference between system and user message
- Time: 20 minutes

## 4. Prompt Engineering for JSON Output
- Read: https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/overview
- What to understand:
  - How to tell Claude to return ONLY JSON
  - How to define the exact shape of JSON you want
  - How to safely JSON.parse() the response
- Time: 30 minutes

## 5. API Key and Environment Setup
- Read: https://docs.anthropic.com/en/api/getting-started
- What to understand:
  - Where to get your API key
  - x-api-key header
  - anthropic-version header (always "2023-06-01")
- Time: 10 minutes

---

## Total Learning Time: ~2 hours
## When to learn it: Only when you reach Phase 8
## Everything before Phase 8: zero AI knowledge needed
